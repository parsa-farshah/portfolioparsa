# Badge

یه کامپوننت بج (Badge) کوچیک برای نمایش یه متن مهم یا برچسب.

## Import

```tsx
import Badge from "./components/shared/Badge";
```

## Props

| نام | نوع | اجباری؟ | توضیح |
|---|---|---|---|
| text | string | required | متنی که داخل بج نمایش داده می‌شه |
| className | string | optional | برای استایل‌دهی اضافه از بیرون |

## مثال

```tsx
<Badge text="hello" />
```
